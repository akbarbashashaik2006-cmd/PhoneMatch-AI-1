# 📱 Shaik Akbar Basha — Smartphone Accessory Expert

> Identify any smartphone model instantly and discover every compatible accessory with professional-grade precision.

---

## ✨ Features

- **Advanced Pattern Identification** — Our expert system identifies the exact brand, model, and generation of any phone from a single photo.
- **Precision Accessory Matching** — Get chargers, cables, cases, screen protectors, earbuds, and stands that are guaranteed to fit your device.
- **Confidence Rating** — Every match includes a professional reliability score.
- **Quick Demo Mode** — Four built-in examples (iPhone 15 Pro, Galaxy S24 Ultra, Pixel 8 Pro, OnePlus 12) — no photo needed.
- **Smart Filter System** — Filter accessories by category (Charger, Case, Audio, etc.) with one click.
- **Drag & Drop + Paste** — Professional file handling with clipboard support.
- **Interactive Shop Map** — Locate real mobile accessory stores near you instantly.
- **Merchant Sales Dashboard** — Professional analytics and inventory management for shop owners.
- **Premium Dark UI** — Responsive, glassmorphic, production-grade design.

---

## 🚀 Quick Start

No build step required. Just open `index.html` in a browser.

```bash
# Option 1 — Local server (Recommended)
npx serve .
# Then visit http://localhost:3000
```
